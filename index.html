How to build

  1. Press Get parts, specs, and images from the web to expand the catalog.
  2. Choose a category and select a part.
  3. Drag it into the matching slot. On iPhone, tap the part and then tap its slot.
  4. Watch the compatibility panel for socket, memory, size, cooling, and power conflicts.
  5. Install all nine categories and run the performance estimate.
  6. Tap an installed part in the list to remove it.
