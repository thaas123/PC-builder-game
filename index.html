How to build

  1. Choose a category and select a part.
  2. Drag it into the matching slot. On iPhone, tap the part and then tap its slot.
  3. Watch the compatibility panel for socket, memory, size, cooling, and power conflicts.
  4. Install all nine categories and run the performance estimate.
  5. Tap an installed part in the list to remove it.
